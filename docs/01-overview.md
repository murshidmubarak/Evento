# EventOps ERP

## Project Purpose
Event management ERP for managing clients, events,
quotations, payments, event managers, workers,
recruitment, wages and event operations.

## Roles

1. Admin
2. Client
3. Event Manager
4. Worker

## Worker Types

- Catering Boy
- Catering Supervisor
- Chef
- Cameraman / Photographer
- Videographer
- Decoration Worker
- Juice Worker
- Host

## Main Business Flow

Client
  ↓
Create Event Request
  ↓
Admin Communication
  ↓
Quotation
  ↓
Client Accepts Quotation
  ↓
Advance Payment
  ↓
Event Confirmed
  ↓
Admin Assigns Event Manager
  ↓
Event Manager Announces Worker Requirements
  ↓
Eligible Workers Receive Opportunity
  ↓
Workers Respond
  ↓
AI / System Selects Workers
  │
  ├── Selected
  └── Not Selected
  ↓
Confirmed Work
  ↓
Attendance
  ↓
Performance Evaluation
  ↓
Wage Calculation
  ↓
Worker Payment
  ↓
Event Completed
  ↓
Feedback / Gallery
  ↓
Admin Revenue / Expense / Profit
